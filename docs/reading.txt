AMMA Project — Current Prototype Summary

1. Project objective

AMMA – Maternal Wellness Suite is a wearable maternal-monitoring prototype designed for the third trimester.

The current prototype focuses on:

Maternal physiological monitoring

Abdominal movement/fetal-movement proxy detection

Local sensor visualization

Wireless/cloud data logging

A foundation for later signal processing and AI-based analysis



---

2. Current hardware architecture

The current prototype uses an ESP32-S3 as the main controller.

Sensors

Component	Quantity	Purpose

MPU6050	2	Abdominal movement/acceleration sensing
Piezoelectric sensor	2	Detect mechanical/vibration signals from the abdominal area
ADS1115	1	High-resolution ADC for piezo signals
OLED	1	Local monitoring/display


Current I²C configuration

Device	Address

OLED	0x3C
ADS1115	0x48
Left MPU6050	0x69
Right MPU6050	0x68


ESP32-S3 I²C:

SDA → GPIO 8
SCL → GPIO 9

I²C speed:

400 kHz


---

3. Sensor arrangement

We currently define the two MPU6050 sensors as:

ML = Left MPU6050 → 0x69
MR = Right MPU6050 → 0x68

The piezo sensors are:

PL = Left Piezo  → ADS1115 A1
PR = Right Piezo → ADS1115 A0

This gives us two spatially separated sensing regions rather than relying on one sensor.


---

4. How the ESP32-S3 acquires data

The ESP32-S3 continuously reads the sensors locally.

Current acquisition interval:

100 ms

Therefore:

100 ms = 10 samples/second

The ESP32-S3 reads:

Piezo

PL raw ADC
PR raw ADC

and converts them to voltage.

MPU6050

For each MPU:

X acceleration
Y acceleration
Z acceleration

The firmware also calculates acceleration magnitude:

Magnitude = √(X² + Y² + Z²)

So we obtain:

ML magnitude
MR magnitude

This is useful because it gives us an orientation-independent measure of overall acceleration.

6. Serial monitoring

The ESP32-S3 also sends detailed information through Serial Monitor at:

115200 baud

This is useful during development because we can inspect the raw sensor behavior before developing the actual detection algorithm.

10. Cloud sampling vs sensor sampling

This distinction is important.

The ESP32-S3 samples sensors at:

10 Hz

but ThingSpeak uploads approximately every:

20 seconds

Therefore:

Sensors
   ↓
10 Hz continuous acquisition
   ↓
ESP32-S3
   ├── OLED
   ├── Serial
   └── ThingSpeak
             ↓
         ~20-second updates

ThingSpeak is therefore currently being used for cloud logging/trending, not as the real-time fetal-movement detector.


---

11. Why this architecture is useful

We deliberately separated local sensing from cloud uploading.

Local side

Fast:

Sensor → ESP32-S3 → processing

This is where future kick/movement detection should happen.

Cloud side

Slower:

Processed/raw values → Internet → ThingSpeak

This gives us:

Historical data

Graphs

Remote monitoring

Dataset collection

Visualization

Future ML dataset development

void connectWiFi()
{
  Serial.println();
  Serial.println("========================================");
  Serial.println("           WIFI CONNECTION");
  Serial.println("========================================");

  Serial.print("Connecting to: ");
  Serial.println(WIFI_SSID);


  WiFi.mode(WIFI_STA);

  WiFi.begin(
    WIFI_SSID,
    WIFI_PASSWORD
  );


  int attempts = 0;


  while (
    WiFi.status() != WL_CONNECTED &&
    attempts < 30
  )
  {
    delay(500);

    Serial.print(".");

    attempts++;
  }


  Serial.println();


  if (
    WiFi.status() == WL_CONNECTED
  )
  {
    Serial.println(
      "WiFi connected successfully!"
    );


    Serial.print(
      "IP Address : "
    );

// =====================================================
// READ SENSORS
// =====================================================

void readSensors()
{

  // ===================================================
  // PIEZO
  //
  // A1 = LEFT PIEZO
  // A0 = RIGHT PIEZO
  // ===================================================

  plRaw =
    ads.readADC_SingleEnded(1);


  prRaw =
    ads.readADC_SingleEnded(0);


  // ===================================================
  // PIEZO VOLTAGE
  // ===================================================

  plVoltage =
    ads.computeVolts(
      plRaw
    );


  prVoltage =
    ads.computeVolts(
      prRaw
    );


  // ===================================================
  // ML = LEFT MPU
  // ADDRESS = 0x69
  // ===================================================

  sensors_event_t accelML;
  sensors_event_t gyroML;
  sensors_event_t tempML;


  mpuLeft.getEvent(
    &accelML,
    &gyroML,
    &tempML
  );


  // ===================================================
  // MR = RIGHT MPU
  // ADDRESS = 0x68
  // ===================================================

  sensors_event_t accelMR;
  sensors_event_t gyroMR;
  sensors_event_t tempMR;


  mpuRight.getEvent(
    &accelMR,
    &gyroMR,
    &tempMR
  );


  // ===================================================
  // STORE LEFT MPU VALUES
  // ===================================================

  mlX =
    accelML.acceleration.x;

  mlY =
    accelML.acceleration.y;

  mlZ =
    accelML.acceleration.z;


  // ===================================================
  // STORE RIGHT MPU VALUES
  // ===================================================

  mrX =
    accelMR.acceleration.x;

  mrY =
    accelMR.acceleration.y;

  mrZ =
    accelMR.acceleration.z;


  // ===================================================
  // ACCELERATION MAGNITUDE
  // ===================================================

  mlMagnitude =
    sqrt(
      mlX * mlX +
      mlY * mlY +
      mlZ * mlZ
    );


  mrMagnitude =
    sqrt(
      mrX * mrX +
      mrY * mrY +
      mrZ * mrZ
    );
}

// =====================================================
// SEND DATA TO THINGSPEAK
// =====================================================

void sendToThingSpeak()
{

  Serial.println();
  Serial.println(
    "========================================"
  );

  Serial.println(
    "Sending AMMA data to ThingSpeak..."
  );


  // ===================================================
  // CHECK WIFI
  // ===================================================

  if (
    WiFi.status() != WL_CONNECTED
  )
  {
    Serial.println(
      "ERROR: WiFi disconnected."
    );

    Serial.println(
      "Skipping ThingSpeak upload."
    );

    Serial.println(
      "========================================"
    );

    return;
  }


  // ===================================================
  // SECURE CLIENT
  // ===================================================

  WiFiClientSecure client;

  // For prototype/testing.
  // Certificate verification disabled.

  client.setInsecure();


  HTTPClient http;


  // ===================================================
  // THINGSPEAK UPDATE URL
  // ===================================================

  String url =
    "https://api.thingspeak.com/update";


  url +=
    "?api_key=";

  url +=
    WRITE_API_KEY;


  // ===================================================
  // FIELD 1
  // PL RAW
  // ===================================================

  url +=
    "&field1=";

  url +=
    String(
      plRaw
    );


  // ===================================================
  // FIELD 2
  // PR RAW
  // ===================================================

  url +=
    "&field2=";

  url +=
    String(
      prRaw
    );


  // ===================================================
  // FIELD 3
  // ML MAGNITUDE
  // ===================================================

  url +=
    "&field3=";

  url +=
    String(
      mlMagnitude,
      2
    );


  // ===================================================
  // FIELD 4
  // MR MAGNITUDE
  // ===================================================

  url +=
    "&field4=";

  url +=
    String(
      mrMagnitude,
      2
    );


  // ===================================================
  // FIELD 5
  // ML X
  // ===================================================

  url +=
    "&field5=";

  url +=
    String(
      mlX,
      2
    );


  // ===================================================
  // FIELD 6
  // ML Y
  // ===================================================

  url +=
    "&field6=";

  url +=
    String(
      mlY,
      2
    );


  // ===================================================
  // FIELD 7
  // MR X
  // ===================================================

  url +=
    "&field7=";

  url +=
    String(
      mrX,
      2
    );


  // ===================================================
  // FIELD 8
  // MR Y
  // ===================================================

  url +=
    "&field8=";

  url +=
    String(
      mrY,
      2
    );


  // ===================================================
  // PRINT URL
  // ===================================================

  Serial.println(
    "Uploading:"
  );

  Serial.println(
    "AMMA sensor data → ThingSpeak"
  );


  // ===================================================
  // HTTP REQUEST
  // ===================================================

  http.begin(
    client,
    url
  );


  int httpCode =
    http.GET();


  // ===================================================
  // RESPONSE
  // ===================================================

  Serial.print(
    "HTTP Response Code: "
  );

  Serial.println(
    httpCode
  );


  if (
    httpCode > 0
  )
  {

    String response =
      http.getString();


    Serial.print(
      "ThingSpeak Response: "
    );

    Serial.println(
      response
    );


    int entryID =
      response.toInt();


    if (
      entryID > 0
    )
    {

      Serial.println();
      Serial.println(
        "****************************************"
      );

      Serial.println(
        " AMMA DATA SENT SUCCESSFULLY"
      );

      Serial.print(
        " Entry ID: "
      );

      Serial.println(
        entryID
      );

      Serial.println(
        "****************************************"
      );
    }
    else
    {

      Serial.println(
        "ThingSpeak returned 0."
      );

      Serial.println(
        "Upload may have been rejected"
      );

      Serial.println(
        "because of the 15-second limit."
      );
    }
  }
  else
  {

    Serial.println(
      "ThingSpeak HTTP request failed."
    );

    Serial.print(
      "Error: "
    );

    Serial.println(
      http.errorToString(
        httpCode
      )
    );
  }


  http.end();


  Serial.println(
    "========================================"
  );
}

// =====================================================
// MAIN LOOP
// =====================================================

void loop()
{

  unsigned long currentMillis =
    millis();


  // ===================================================
  // SENSOR ACQUISITION
  //
  // 100 ms = 10 Hz
  // ===================================================

  if (
    currentMillis -
    lastSensorRead >=
    SENSOR_INTERVAL
  )
  {

    lastSensorRead =
      currentMillis;


    // Read sensors

    readSensors();


    // Serial output

    printSensorData();


    // OLED

    updateOLED();
  }


  // ===================================================
  // THINGSPEAK
  //
  // EVERY 20 SECONDS
  // ===================================================

  if (
    currentMillis -
    lastThingSpeakUpdate >=
    THINGSPEAK_INTERVAL
  )
  {

    lastThingSpeakUpdate =
      currentMillis;


    // Check WiFi

    if (
      WiFi.status() != WL_CONNECTED
    )
    {

      Serial.println();
      Serial.println(
        "WiFi disconnected."
      );

      connectWiFi();
    }


    // Upload

    if (
      WiFi.status() == WL_CONNECTED
    )
    {

      sendToThingSpeak();
    }
    else
    {

      Serial.println(
        "Upload skipped: WiFi unavailable."
      );
    }
  }
}

// MR = RIGHT MPU = 0x68
Adafruit_MPU6050 mpuRight;


// =====================================================
// SETUP
// =====================================================

void setup() {

  Serial.begin(115200);

  delay(1000);


  // ===================================================
  // I2C
  // ===================================================

  Wire.begin(
    SDA_PIN,
    SCL_PIN
  );

  Wire.setClock(400000);


  Serial.println();
  Serial.println("================================");
  Serial.println("       AMMA RAW SENSOR TEST");
  Serial.println("================================");

  Serial.println();
  Serial.println("FINAL SENSOR MAPPING:");
  Serial.println("PL = Left Piezo  -> ADS A1");
  Serial.println("PR = Right Piezo -> ADS A0");
  Serial.println("ML = Left MPU    -> 0x69");
  Serial.println("MR = Right MPU   -> 0x68");
  Serial.println();


  // ===================================================
  // OLED
  // ===================================================

  if (
    !display.begin(
      SSD1306_SWITCHCAPVCC,
      OLED_ADDR
    )
  ) {

    Serial.println("OLED ERROR");

    while (1);
  }

  Serial.println("OLED 0x3C: OK");


  // ===================================================
  // ADS1115
  // ===================================================

  if (
    !ads.begin(
      ADS_ADDR,
      &Wire
    )
  ) {

    Serial.println("ADS1115 ERROR");

    while (1);
  }


  // ±4.096 V range

  ads.setGain(
    GAIN_ONE
  );


  // Fast conversion rate

  ads.setDataRate(
    RATE_ADS1115_860SPS
  );


  Serial.println("ADS1115 0x48: OK");


  // ===================================================
  // ML = LEFT MPU
  // ADDRESS = 0x69
  // ===================================================

  if (
    !mpuLeft.begin(
      ML_ADDR,
      &Wire
    )
  ) {

    Serial.println("ML ERROR");

    while (1);
  }


  Serial.println("ML 0x69: OK");


  // ===================================================
  // MR = RIGHT MPU
  // ADDRESS = 0x68
  // ===================================================

  if (
    !mpuRight.begin(
      MR_ADDR,
      &Wire
    )
  ) {

    Serial.println("MR ERROR");

    while (1);
  }


  Serial.println("MR 0x68: OK");


  // ===================================================
  // MPU CONFIGURATION
  // ===================================================

  mpuLeft.setAccelerometerRange(
    MPU6050_RANGE_8_G
  );

  mpuRight.setAccelerometerRange(
    MPU6050_RANGE_8_G
  );


  mpuLeft.setGyroRange(
    MPU6050_RANGE_500_DEG
  );

  mpuRight.setGyroRange(
    MPU6050_RANGE_500_DEG
  );


  mpuLeft.setFilterBandwidth(
    MPU6050_BAND_21_HZ
  );

  mpuRight.setFilterBandwidth(
    MPU6050_BAND_21_HZ
  );


  // ===================================================
  // READY SCREEN
  // ===================================================

  display.clearDisplay();

  display.setTextColor(
    SSD1306_WHITE
  );


  display.setTextSize(2);

  display.setCursor(
    25,
    5
  );

  display.println(
    "AMMA"
  );


  display.setTextSize(1);

  display.setCursor(
    18,
    30
  );

  display.println(
    "RAW SENSOR TEST"
  );


  display.setCursor(
    22,
    45
  );

  display.println(
    "Sensors Ready"
  );


  display.display();

  delay(1500);
}
